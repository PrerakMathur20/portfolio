# Cloudflare Workers (with Static Assets) Deployment Guide

## Prerequisites

1. Install Wrangler CLI:
   ```bash
   npm install -g wrangler
   # or install it locally (already added to devDependencies)
   npm install
   ```

2. Login to Cloudflare:
   ```bash
   wrangler login
   ```

## Deployment Commands

### 1. Deploy to Production
```bash
npm run deploy:cf:prod
```
This will:
- Build the project (`npm run build`)
- Deploy to Cloudflare Workers with static assets

### 2. Deploy to Preview
```bash
npm run deploy:cf:preview
```
This will:
- Build the project
- Deploy to preview environment

### 3. Deploy (without building)
```bash
npm run deploy:cf
```
Use this if you've already built the project and just want to deploy the `build/` folder.

### Alternative: Direct wrangler command
```bash
npm run build
wrangler deploy
```

## First-Time Setup

### Via Wrangler CLI (Recommended)

1. Ensure you have built the project:
   ```bash
   npm run build
   ```

2. Login to Cloudflare:
   ```bash
   wrangler login
   ```

3. Deploy for the first time:
   ```bash
   npm run deploy:cf:prod
   ```

4. Follow the prompts to:
   - Select your Cloudflare account
   - Confirm the worker name (portfolio)

5. Your site will be deployed to: `https://portfolio.<your-account>.workers.dev`

## Environment Variables

Environment variables are configured in `wrangler.toml`:

### Current Environment Variables:
- `NEXT_PUBLIC_WEBSITE_URL` - Your website URL (currently: https://prerak.tech)
- `NEXT_PUBLIC_API_URL` - Your API endpoint URL (currently: https://api.prerak.tech)

To add more environment variables:
1. Edit `wrangler.toml` and add them under `[vars]`
2. Or use Cloudflare Dashboard → Workers & Pages → Your Worker → Settings → Variables

## Important Notes

### Static Site with Workers
This configuration uses **Cloudflare Workers with Static Assets**:
- ✅ All static files from `build/` directory are served automatically
- ✅ Fast edge delivery
- ✅ Perfect for static Next.js exports
- ✅ Can add custom worker logic in `src/index.js` if needed

### Serverless Functions
Your current `functions/` directory contains AWS Lambda functions. To add serverless functionality on Cloudflare Workers:
1. Edit `src/index.js` to add custom request handling
2. Use Workers API for dynamic routes
3. Example: Add API endpoints, authentication, etc.

### Custom Domain
To use your custom domain (prerak.tech):
1. Go to Cloudflare Dashboard → Workers & Pages → Your Worker
2. Click "Triggers" tab
3. Add custom domain under "Custom Domains"
4. Follow the DNS configuration steps

### Routes
By default, your worker will be available at:
- `https://portfolio.<your-account>.workers.dev`

After adding a custom domain:
- `https://prerak.tech`

## Monitoring

- **Deployment logs**: Available in terminal after deployment
- **Analytics**: Cloudflare Dashboard → Workers & Pages → Your Worker → Analytics
- **Logs**: Use `wrangler tail` to view real-time logs

## Troubleshooting

### Build fails
- Run `npm run build` locally first to verify it works
- Check for any file path issues in build output
- Ensure Node version is compatible (18+)

### Deployment fails
- Make sure you're logged in: `wrangler whoami`
- Verify `build/` directory exists and has content
- Check wrangler.toml configuration is correct

### Site not updating
- Clear browser cache
- Purge Cloudflare cache in Dashboard
- Verify deployment completed successfully: check terminal output
- Use `wrangler tail` to see live logs

### "No such file or directory" error
- Ensure you run `npm run build` before deploying
- Check that `build/` directory exists
- Verify assets.directory in wrangler.toml points to correct folder
